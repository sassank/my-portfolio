# My Portfolio

Portfolio de Sassan Khalafi, développeur web full stack à Paris : expérience, projets et contact.

Site statique en HTML5 et CSS3, sans framework ni étape de build, avec thème clair / sombre automatique et mise en page responsive.

En ligne : https://sassank.github.io/my-portfolio/

## Structure

```
index.html          Page d'accueil (présentation, expérience, projets, contact)
projects/           Une page par projet
  crm-saas.html       Back-office CRM multi-tenant (SaaS)
  printerwatch.html   PrinterWatch, supervision d'imprimante en temps réel
  calmedica.html      Calmedica, transcription d'appels patients
  vitedrive.html      ViteDrive, location de véhicules
  safranco.html       Safranco, site vitrine PrestaShop
  own-cloud.html      Serveur ownCloud sous Debian
assets/             Captures d'écran et favicon
files/              CV, photo de profil, documentation PDF
```
